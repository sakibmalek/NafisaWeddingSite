# Nafisa & Sakib — GitHub Pages wedding site

## Files
- `index.html` — page structure/content
- `styles.css` — mobile-first responsive styling
- `script.js` — Bangladesh-time countdown
- `assets/hero.jpg` — your top wedding image (you add this)

## Add your hero image
Put your image in the `assets` folder and name it exactly:

`hero.jpg`

Recommended: around 1080 × 1350 px or larger, with important subjects near the center.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `wedding`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**.
6. Click **Save**.
7. GitHub will show the public Pages URL after deployment.
